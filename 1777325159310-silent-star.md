# Implementation Plan: Next.js AI Agent for Best Product Recomodation

## Goal
Build a web-based AI agent using Next.js that compares products from e-commerce sites using free tools/APIs. The agent uses a Modular Agentic Loop with ReAct pattern for reasoning and tool execution.

## Architecture Overview
- **Frontend Layer**: Next.js 15 App Router with Vercel AI SDK for real-time streaming
- **Orchestrator Layer**: Server Actions/Route Handlers with ReAct loop using Groq Llama 3
- **Tool Layer**: Search (Tavily), Extraction (Firecrawl), Data Normalization (custom logic)

## Detailed Components

### Frontend
- Framework: Next.js 15 with App Router
- Streaming: Vercel AI SDK
- UI: Search form, real-time thoughts display, recommendation grid
- Styling: Tailwind CSS

### Orchestrator
- Implementation: API Route Handler
- Pattern: ReAct (Reason -> Act -> Observe -> Repeat)
- LLM: Groq Llama 3 (free tier)
- State: In-memory for reasoning loop

### Tools
- Search: Tavily API (1k free searches/month)
- Extraction: Firecrawl API (500 free credits)
- Normalization: JavaScript functions for standardization

## System Flow
1. Intent Analysis: Parse user query for product type, constraints
2. Product Discovery: Search for 5-10 e-commerce URLs
3. Structured Extraction: Scrape URLs for product data
4. Synthesis & Ranking: Compare and rank products
5. Streaming Output: Display results in real-time

## Implementation Steps
1. Project Setup: Create Next.js app, install dependencies
2. Frontend Development: Build UI components
3. Orchestrator: Implement ReAct loop with Groq
4. Tool Integration: Connect Tavily and Firecrawl
5. Data Normalization: Add standardization logic
6. Testing: Test with sample queries
7. Deployment: Deploy to Vercel

## Free Tools Verification
- Groq: Free tier available
- Tavily: 1,000 searches/month free
- Firecrawl: 500 credits free
- Vercel: Free hosting
- Next.js: Open source

## Assumptions

- Free API limits are sufficient for development/testing
- Indian e-commerce focus (INR currency, local sites)
